# Adage: Daily Quotes — Website

Static website for **Adage: Daily Quotes**, hosted on GitHub Pages.

## Pages
- `index.html` — Landing page (app overview, features, widget preview, privacy summary)
- `privacy-policy.html` — Full privacy policy

## Deploy to GitHub Pages
1. Create a new GitHub repo (e.g. `Adage-Website` or `adage-site`).
2. Push this folder to the repo.
3. In repo settings → Pages → Source: `Deploy from a branch` → `main` → `/ (root)`.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.

## Privacy Policy URL for Play Console
Once deployed, use this URL in Play Console → Data safety → Privacy policy URL:
```
https://<username>.github.io/<repo-name>/privacy-policy.html
```

## Local preview
Just open `index.html` in a browser — no build step needed.
